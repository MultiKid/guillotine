# Guillotine Prototype

Phase 1 scaffold for a local pass-and-play browser card game prototype.

This repository currently contains placeholder files only:

- No complete gameplay implementation yet.
- No server logic yet.
- No database, accounts, authentication, AI, matchmaking, or app store deployment.
- Card data is intentionally placeholder/sample content until the final card list and effects are supplied.

## Getting Started

After dependencies are installed:

```bash
npm run dev
```

Then open `http://localhost:3000`.
